# Support

For installation help, usage questions, or reproducible bugs, open a GitHub issue using the appropriate template. Include your operating system, Node.js version, DSH version, dsh-explain version, and the smallest synthetic reproduction.

Before posting logs, remove API keys, Session content, `$DSH_HOME` data, absolute paths, and model responses that contain private work material. Security vulnerabilities must follow [SECURITY.md](SECURITY.md) and must not be filed publicly.
