    - heading "TypeScript 可辨识联合与类型收窄" [level=3]
    - text: 来源 real-v03… · 当前 回合 1
    - time: 2026/9/15 17:23:01
    - text: 当前
    - heading "是什么" [level=4]
    - paragraph: "用一个共享的字面量字段（如 kind: \"ok\" | \"error\"）区分多个对象类型，构成可辨识联合。当用 result.kind === \"ok\" 比较时，TypeScript 做类型收窄，只在匹配的分支里把 result 缩成对应的类型，所以能安全访问该分支独有的 value；error 分支没有 value，收窄前访问会报错。"
    - heading "为什么" [level=4]
    - paragraph: 联合类型表示“多个形状之一”，编译器不能默认某个独有字段一定存在。字面量判别字段充当标签，=== 比较字面量让编译器排除其他分支，从而精确缩小类型，避免在运行时访问 undefined 的属性。
    - heading "常见坑" [level=4]
    - paragraph: 常见错误是忘了先判断就访问 result.value（报 Property 'value' does not exist on type 'Result'），或在 if 分支外用收窄后的类型。正确做法是在 if (r.kind === "ok") 分支内使用 r.value，else 分支使用 r.message。
