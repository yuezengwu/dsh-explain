# dsh-explain PRD(P0 定稿)

> 状态:**已定稿**(2026-08-12)· 范围:仅 P0 · 本文档是产品需求的唯一事实源,后续架构与实现以本文为准

## 定位

**学习模式**:开关打开后,agent 工作时**自主判断时机**,在主对话行内讲解涉及的知识点;右侧悬浮窗提供**反馈按钮**(✓ 懂了 / ✗ 没懂)。

## 目标用户

所有 DSH 用户——不按身份限定。讲解的价值取决于"任务涉及的知识是否超出用户熟悉范围";是否讲解、讲多深,由 agent 结合上下文自主判断。

## P0 功能清单

| 功能 | 说明 |
|---|---|
| 开关 | `/explain on\|off`,默认关,按会话记忆 |
| 行内讲解 | agent 自主判断时机(何时讲、讲什么、讲多少),知识点卡片:是什么/为什么/坑,默认可折叠 |
| 右侧悬浮窗 | 主对话右侧悬浮,展示当前知识点 + 两按钮:✓ 懂了 / ✗ 没懂;可折叠成小按钮;无文字输入 |
| 反馈闭环 | ✓ 懂了 → 该主题标记掌握,同类不再讲;✗ 没懂 → 触发换一种说法重新讲解 |
| 防吵三件 | 同主题去重、卡片默认可折叠、懂了反馈 |

## 交互形态

```
┌─ 主对话 ────────────────────────────┐  ┌─ 悬浮窗(右侧) ─┐
│ 用户:部署到生产环境                  │  │ [📚 当前知识点] │
│ agent:好的,先跑测试……              │  │ jq —— JSON 命令行 │
│  ┌─ 📚 知识点 ──────────────────┐   │  │ 处理工具         │
│  │ jq 是什么/为什么/坑          │   │  │                  │
│  │ (可折叠)                     │   │  │ [✓ 懂了] [✗ 没懂] │
│  └──────────────────────────────┘   │  │ (可折叠成小按钮)  │
└─────────────────────────────────────┘  └──────────────────┘
```

## 非目标(P0 明确不做)

- 行内追问(已移出 P0,是否进后续版本待定)
- 悬浮窗内文字输入/对话
- 深度档位与自适应(初学/进阶/专家)
- 跨会话知识档案
- 知识点与主对话消息的上下文关联跳转
- 知识沉淀卡片(后期与 dsh-edu 集成)
- 决策点讲解(agent 选方案时解释"为什么")

## 验收标准

1. 开关打开后,主对话出现讲解,且不干扰任务本身
2. 悬浮窗两按钮生效:懂了 → 同类不再讲;没懂 → 换说法重讲
3. 全程无人抱怨"太吵"(折叠 + 去重 + 反馈生效)
