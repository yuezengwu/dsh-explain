# dsh-explain PRD(P0 草案)

> 状态:**P0 草案(非定稿)**——产品方向成立,平台可行性已闭合(2026-08-12)
> 技术方案见 [./ARCHITECTURE.md](./ARCHITECTURE.md);本文档与架构 v4 同步演进

## 定位

**学习模式**:开关打开后,explain 独立循环**自主判断时机**,在主对话行内讲解涉及的知识点;回合尾部提供反馈按钮(✓ 懂了 / ✗ 没懂),主对话循环互不干扰。

## 目标用户

所有 DSH 用户——不按身份限定。讲解的价值取决于"任务涉及的知识是否超出用户熟悉范围";是否讲解、讲多深,由 explain 循环自主判断。

## P0 功能清单

| 功能 | 说明 |
|---|---|
| 开关 | `/explain on\|off`,默认关,按会话记忆;关闭时零辅助模型请求、零 explain 事件 |
| 行内讲解 | explain 循环自主判断时机,知识点卡片(是什么/为什么/坑),渲染于消息流(`conversation.chat.node`) |
| 回合尾部操作 | 本轮知识点小结 + 两按钮(✓ 懂了 / ✗ 没懂),渲染于回合尾部(`conversation.chat.turnTail`) |
| 反馈闭环 | ✓ 懂了 → 抑制当前会话内同一 TopicId;✗ 没懂 → 关联原讲解的新 revision 重讲 |
| 防吵 | 同 TopicId 去重、卡片可折叠、懂了反馈 |

## 呈现位置(P0 定稿)

| 元素 | 槽位 | 位置 |
|---|---|---|
| 讲解卡片 | `conversation.chat.node` | 消息流内行内 |
| 知识点小结 + 反馈按钮 | `conversation.chat.turnTail` | 回合节点尾部 |
| ~~右侧悬浮窗~~ | — | **移出 P0**:主仓库无空闲右侧浮层扩展位,真悬浮窗需主仓库加槽(后续评估) |

## 非目标(P0 不做)

- 右侧悬浮窗(移出 P0,后续评估)
- 悬浮窗内文字输入/对话
- 深度档位与自适应 / 跨会话知识档案
- 知识沉淀(后期与 dsh-edu 集成)/ 决策点讲解
- 行内追问(移出,是否进后续版本待定)

## 验收标准(可自动验证)

1. **关闭零成本**:开关关闭时,产生零辅助模型请求和零 explain 事件
2. **渲染正确**:固定模型夹具输出讲解时,行内卡片与回合尾部操作正确出现
3. **主模型不变**:explain 事件不改变主模型 `deriveMessages()` 结果
4. **✓ 语义**:只抑制当前会话内同一 `TopicId`
5. **✗ 语义**:产生关联到原 `ExplanationId` 的新 revision
6. **持久一致**:刷新、恢复和分页后讲解与反馈状态一致
7. **失败隔离**:模型失败、取消、迟到结果不阻塞主 turn
8. **测试伴随**:GUI 单测、keyless Web replay/snapshot 和真实流程 GIF 从首个 UI PR 开始
